# Mbeka-Trust-School-School-Management-System
this is a backend project for mbeka school 

## Features
- Rest Api endpoints
- User Authentication with jwt
- Sql database intergration
- Error handling and middleware
- Redis Cache for caching 

###  Preliquisites

Before  running this project ,ensure you have the following installed

- Nodejs is installed on your machine
- A relational database in installed on your machine 
- Redis is installed on your machine

## Getting Started 

Follow the following steps to set up the project

### Clone the Repository

git clone  https://github.com/joe-nguwo/MBEKA-TRUST-SCHOOL-SYSTEM-BACKEND.git

### Install Dependieces

npm install

### Env File Creation

create a .env file in the root directory 

### Run the Application 

run npm run dev in the terminal
